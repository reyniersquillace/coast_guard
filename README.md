This is a `numpy > 2.0` and `python > 3.0` update to `coast_guard` by Patrick Lazarus.

# Installation

`git clone git@github.com:reyniersquillace/coast_guard.git`

## Setup with PyPI:

`pip install .`

Make sure you set up the config path, and add it to your .bashrc if need be:

`export COASTGUARD_CFG=/path/to/coast_guard/configurations`

## Setup with `pixi`:

From inside `coast_guard`, run:

`pixi init`
